# 🚀 COMO USAR O SITE - VERSÃO SIMPLIFICADA

## 1️⃣ Iniciar (Windows)

Duplo-clique em:
```
START.bat
```

Isto irá:
- ✅ Iniciar o servidor automaticamente
- ✅ Abrir o site no navegador
- ✅ Tudo pronto para usar!

---

## 2️⃣ Fluxo de Utilização

1. **Clique em "Manuais"** no site
2. **Escolha o manual** que quer estudar
3. **Escreva a senha:**
   - Exemplo: `Standard 1234`
   - Clique em "Estudar"
4. **O PDF abre automaticamente** numa nova aba!

---

## 3️⃣ Senhas Válidas

```
Standard 1234
Foundation 5555
Intermediate 1111
Fluency Acceleration
Joy 2024
Autodidata 5555
```

---

## ⚠️ Se der erro?

### Erro: Python não encontrado
- Instale Python: https://python.org
- Durante instalação, **marque "Add Python to PATH"**

### PDF não abre
- Certifique-se que `START.bat` está a correr (check a janela de comando)
- Tente recarregar a página (F5)

### Fechar o site
- Feche a janela do navegador
- Feche a janela de comando do servidor

---

**Isto é tudo! Muito simples.** 🎉
